# Username Availability (Mini Backend Feature)

## Overview

This project simulates a backend feature that checks if a username is available and adds it if valid.

## What It Does

* Receives a username (like an API request)
* Normalizes input (`trim + lowercase`)
* Checks if username already exists
* Adds user if available
* Handles async behavior using Promises and `async/await`

## Concepts Used

Datatypes • Functions • Conditionals • Loops • Array/String methods • Promises • `setTimeout` • `async/await` • Error handling

## Run

```
node index.js
```
