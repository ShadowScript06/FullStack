# Expense Analytics (JavaScript)

## Overview

A small JavaScript project that cleans raw expense data and generates useful insights like **total spend, category-wise breakdown, highest expense, and average spend**.

## Concepts Used

* `map()` → Data cleaning & transformation
* `reduce()` → Totals and category aggregation
* `forEach()` → Finding highest expense
* Type conversion & normalization

## Run Project

```bash
node index.js
```

## Sample Output

```
Total Spend: 35674
CategoryBreakdown: {"food":10230,"travel":7645,"essentials":12980,"fun":4819}
Highest Expense: 4850
Average Spend: 594.56
```

## Goal

Practice **real-world data processing logic** used in backend/fintech systems.
